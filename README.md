# Job Matcher

Scrapes remote job listings and scores them against your resume using TF-IDF cosine similarity. Surfaces keyword gaps to help target your resume for specific roles.

## Features
- Live job scraping from RemoteOK
- Resume parsing from PDF or TXT
- TF-IDF cosine similarity scoring
- Keyword gap analysis
- Streamlit UI

## Setup
pip install -r requirements.txt

## Usage
streamlit run app.py
